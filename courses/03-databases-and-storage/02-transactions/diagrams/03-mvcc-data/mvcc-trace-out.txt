   FOR KEY SHARE                        ok                 ok                 ok           CONFLICT
   FOR SHARE                            ok                 ok           CONFLICT           CONFLICT
   FOR NO KEY UPDATE                    ok           CONFLICT           CONFLICT           CONFLICT
   FOR UPDATE                     CONFLICT           CONFLICT           CONFLICT           CONFLICT

10. Foreign keys: a child INSERT takes FOR KEY SHARE on the parent row
====================================================================================================
-- parent row locks while the child INSERT is open
   locked_row | multi | modes
   (0,1) | False | ['For Key Share']
   parent holder: UPDATE parent SET credits = credits + 1 (non-key)    -> child INSERT: ok
   parent holder: SELECT ... FOR NO KEY UPDATE                         -> child INSERT: ok
   parent holder: SELECT ... FOR UPDATE                                -> child INSERT: BLOCKED (still waiting after 1 s)
   parent holder: UPDATE parent SET id = 2 (key column)                -> child INSERT: BLOCKED (still waiting after 1 s)
